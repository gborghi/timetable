\chapter{Constraints (HARD + SOFT)}
\label{ch:vincoli_en}

HARD: no overlap (teacher in one class at a time, class with one teacher per slot), hour coverage of all cattedre, daily start at h=8, consecutive hours, presence at h=11 (the H1/H2/H3 trio). Native locks. C1 (compresenza/coteach), C2 (sostegno DVA), C3 (potenziamento, parallel intra-class, group inter-class). SOFT: daily uniformity, free-day preferences, sixth-hour penalties, five/one day load.
