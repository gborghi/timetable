\noindent\small
\textbf{\sffamily Colophon}\\[0.3em]
This English edition is set in EB Garamond for body text and Lato
for headings, with Inconsolata for code blocks. Compilation is
done with \texttt{lualatex} (TeX Live), \texttt{biber} for
bibliography and \texttt{makeindex} for the analytical index.
The \LaTeX{} source lives in \texttt{docs/manual\_en.tex} with
chapters in \texttt{docs/manual/chapters\_en/}; the bibliography is
shared with the Italian edition in \texttt{docs/manual/bibliography.bib}.
The build pipeline is in \texttt{docs/build\_manual.sh} which emits
\textbf{both} \texttt{manual.pdf} (Italian) and
\texttt{manual\_en.pdf} (English) in a single invocation.

\bigskip
\noindent\textbf{\sffamily Note on translation}: the Italian edition
remains the primary reference. This English edition fully translates
the introduction, the BP-related chapters and the benchmark chapter;
all other chapters carry an English summary that points the reader to
the corresponding Italian chapter for the full narrative. Where
Italian-school context is necessary (for instance the legal frame of
the \emph{contratto collettivo nazionale}, the role of the
\emph{insegnante di sostegno}, or the meaning of \emph{indirizzo di
studio}), explanatory notes are added in the English text.

\bigskip
\noindent
The repository version corresponds to the most recent commit
visible in \texttt{git log --oneline -- docs/}.
Errors and suggestions can be reported as issues on the GitHub
repository at \url{https://github.com/gborghi/timetable}.
