# branding/screenshots/

Screenshot della UI per la documentazione (README, manuale tecnico).

## Convenzione di naming

`<page>_<state>.png` -- in lowercase con underscore. Esempi:

- `dashboard_imported_small.png`
- `teachers_edit_modal.png`
- `schedule_matrix_class_2A.png`
- `schedule_drag_preview.png`
- `assenze_supplenze_friday.png`
- `monitor_event_expanded.png`
- `constraints_conflicts_panel.png`

## Dimensioni

- Browser portion: full-page, 1500px di larghezza minima (per
  catturare la nav e una pagina completa).
- Mobile portion (per docs PWA / responsivita'): 375x812.

## Note

Questi screenshot sono utili dalla **versione finale dei loghi**:
aggiungili solo dopo che il branding e' definitivo, altrimenti vanno
rifatti.
