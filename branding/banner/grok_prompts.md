# Grok prompts: banner piTantum

Banner promozionali. Tutti devono includere wordmark **$\pi$Tantum**
+ epigrafe Seneca + i 3 elementi visivi (clessidra, $\pi$, alloro).

## Prompt 1: GitHub social preview -> banner_github.png

```
Horizontal banner image for GitHub repository social preview,
1280x640 PNG. Layout: on the left third, the piTantum logo mark
(lowercase Greek pi with hourglass embedded between vertical
strokes, encircled by a delicate laurel wreath, in the brand
palette: indigo #1e3a5f, gold #c9a23a). On the right two-thirds,
the wordmark "piTantum" in elegant serif (Cormorant Garamond
style), with the leading "pi" rendered as the Greek letter in
italic gold and the rest in upright indigo. Below the wordmark,
the epigraph in italic gray: "Omnia, Lucili, aliena sunt, tempus
tantum nostrum est." Attribution underneath in smaller font:
"Seneca, Ep. I, 1". Background: ivory (#f7f1de) with subtle
classical ornament (faded laurel sprigs at corners).
Style: classical, editorial, premium, mathematical.
```

Dimensioni: **1280x640 PNG**. Va caricato in
GitHub -> Settings -> General -> Social preview.

## Prompt 2: Open Graph image -> og_image.png

```
Open Graph share image, 1200x630 PNG. Same composition as the
GitHub social preview but optimized for Telegram / WhatsApp /
Discord readability at small thumbnail sizes: the wordmark is
larger and bolder, the epigraph is shorter ("Tempus tantum
nostrum est" only). The piTantum mark on the left is more
compact. Maintain palette indigo (#1e3a5f), gold (#c9a23a),
ivory (#f7f1de) background.
```

Dimensioni: **1200x630 PNG**.

## Prompt 3: README hero -> banner_readme.png

```
Wide narrow banner for the top of a README.md file, 1200x300 PNG.
Centered: the piTantum logo (small, 80x80) on the left, then the
wordmark "piTantum" big serif, then below the epigraph italic.
Decorative laurel sprig top-left and bottom-right corners.
Background: ivory (#f7f1de) with a horizontal gold (#c9a23a)
rule beneath the epigraph. Plenty of margin on top/bottom.
Style: editorial, suitable as a markdown header image.
```

Dimensioni: **1200x300 PNG**.

---

## Prompt 4: Dashboard hero -> banner_dashboard.png

```
Inspiring banner for the app's Dashboard page, 1500x300 PNG. A
soft horizontal scene: a stylized abacus or mathematical grid
fading from left to right into a Roman scroll with the
"piTantum" wordmark and the Seneca epigraph in calligraphic
serif. Color palette: indigo #1e3a5f, gold #c9a23a, terra di
Siena #9c4a1c, ivory #f7f1de. Includes a small hourglass icon
on the right third with sand falling.
Style: warm, classical, motivational without being kitsch.
```

Dimensioni: **1500x300 PNG**.
