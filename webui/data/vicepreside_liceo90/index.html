Guida operativa per il vicepreside · piTantum · tutti i file e i passaggi per riprodurre l'orario ottimizzato

La scuola in breve

90 classi6 indirizzi187 docenti settimana 6×6 (lun–sab, 8–14)84 aule + 3 palestre biennio a turnazione9 alunni con sostegno

Indirizzi: scientifico, scienze applicate, linguistico, classico, scienze umane, economico-sociale. Obiettivo dimostrato: far stare 90 classi in 87 aule (aule < classi) grazie alla turnazione del biennio e alla condivisione palestra, con 0 lezioni non piazzate, giorno libero di 1ª scelta soddisfatto al ~99%, biennio 36/36.

2 · Come caricarli + i pochi settaggi non-Excel

Caricamento

Dashboard → Importazione dati: per ogni file scegli l'entità e carica. Alla PRIMA volta usa modalità replace (svuota e ripopola); per aggiornamenti successivi upsert. Ordine consigliato: materie → aule → docenti → classi → studenti → cattedre.

Settaggi che NON stanno nell'Excel

  • Settimana (tab Ore): 6 giorni lun–sab × 6 ore 8:00–14:00. È l'unica configurazione strutturale da fare a mano.
  • Sostegno: per ogni alunno flaggato (file 5) assegna in UI il docente di sostegno all'alunno; imposta il docente su compresenza=sempre così il sostegno resta nell'aula della classe (non prenota un'aula in più).

Tutto il resto (giorni liberi con priorità, biennio a turnazione, palestra obbligatoria, policy aula ibrida, palestra a 2 classi) è già dentro le colonne dei file Excel — niente da reinserire.

3 · I run da lanciare (pipeline)

  1. Phase B — Orario (sezione Ottimizza): cp_sat_scope = day, phase_a_mode = always, use_decomposition = true (decomposizione per giorno), respect_room_capacity = ON (tetto = 84 aule standard). Questo colloca le lezioni rispettando capienza-aule e giorni liberi.
  2. Metaeuristica LNS: rifinitura (chiude i buchi, migliora i soft) sulla soluzione attiva.
  3. Assegnazione aule (rooms): assegna le aule fisiche. Il vincolo soft room-pool (attivo di default) tiene ogni classe in un pool ridotto di aule (~2–3, non ~25): la classe cambia aula solo quando serve (palestra, o per occupare l'aula di chi è in palestra).

Alternativa rapida: dal menù Importa modelli risolti scegli liceo90 per caricare direttamente la scuola già risolta (anagrafica + vincoli + orario), oppure ripristina lo snapshot DB dalla card Import/Export DB.
